Azure Load Balancer vs Application Gateway

Design Comparison and Cloud Implementation

This project compares Microsoft Azure Load Balancer and Azure Application Gateway, focusing on their architecture, traffic distribution, routing capabilities and security features.

Objectives

Understand Layer 4 and Layer 7 load balancing.

Design Azure Load Balancer and Application Gateway architectures.

Compare their features and use cases.

Explore traffic routing and high availability.

Azure Services

Azure Load Balancer, Application Gateway, Virtual Network, Virtual Machines, Network Security Groups, Public IP and Azure Monitor.
